# Code of conduct

EVO Panel is built for sim racing communities. In issues, pull requests, the wiki and the Discord:

- Be respectful and patient, whatever someone's level or language (English and French are both welcome).
- Criticise code and ideas, never people.
- No harassment, insults, discrimination or spam.
- Never post someone else's personal data, passwords or server credentials.

Maintainers may edit or remove content and block accounts that break these rules.
To report a problem privately, write to contact@zyphro.fr.
